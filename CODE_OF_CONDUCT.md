# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short
- Be respectful and welcoming. Disagree about ideas, not people.
- No harassment, discrimination, personal attacks or sharing others' private information.
- Assume good intent, and give constructive feedback.

## Scope
This applies in all project spaces (issues, pull requests, discussions) and when representing the project elsewhere.

## Reporting
Report unacceptable behaviour privately to the maintainers through GitHub (for example by contacting a maintainer listed on the repository). Reports are handled confidentially. Maintainers may remove, edit or reject contributions, and may temporarily or permanently ban contributors, for behaviour that violates this code.
